# WorldHistory Atlas

Красивое многостраничное React/Vite-приложение для поиска и изучения мировой истории: эпохи, история стран, военные конфликты, маршруты обучения и каталог источников.

## Возможности

- Главная страница с учебными маршрутами и быстрыми переходами.
- Глобальный поиск по эпохам, странам и конфликтам.
- Страница эпох мировой истории.
- Страница историй стран с фильтрами по регионам.
- Интерактивная страница военных конфликтов.
- Каталог проверенных источников: энциклопедии, архивы, карты, музеи и академические инструменты.
- Адаптивный glassmorphism-дизайн.

## Запуск

Требуется Node.js 22.5 или новее: backend использует встроенный модуль SQLite.

```bash
npm install
npm run dev
```

Сборка:

```bash
npm run build
```


## Запуск на Windows через bat-файл

Дважды кликните `start-worldhistory.bat`.

Скрипт:

1. проверит наличие Node.js и npm, а также версию Node (нужна 22.5+ — иначе backend не запустится, а в браузере будет ошибка 502);
2. предупредит, если порты 3001/5173 уже заняты прошлым запуском;
3. установит зависимости при первом запуске;
4. запустит dev-сервер (backend на 3001 и frontend на 5173);
5. сам откроет `http://localhost:5173/` в браузере, когда оба сервера будут готовы.

Если страница показывает «Ошибка API: 502» — значит, frontend работает, а backend нет: посмотрите лог в окне консоли, там будет причина (чаще всего устаревший Node.js или занятый порт 3001).

Для остановки сервера нажмите `Ctrl+C` в окне консоли.


## Backend API

В проект добавлен первый backend-каркас на Express.

Команды:

```bash
npm run dev      # frontend + backend
npm run dev:web  # только Vite
npm run dev:api  # только API
```

Эндпоинты:

- `GET /api/health`
- `GET /api/search?q=Франция`
- `GET /api/dossier/:query`
- `GET /api/source/analyze?url=https://example.com`
- `GET /api/network/settings` — текущие настройки подключения и автопоиск Tor
- `PUT /api/network/settings` — сменить маршрут (direct / tor / custom)
- `POST /api/network/test` — диагностика: проверяет Wikipedia прямым маршрутом и через Tor (9150/9050)

Пока API является каркасом: он работает с локальными seed-данными и универсальным планом досье. Следующий этап — подключить реальный web search, парсинг HTML/PDF, кэш и базу данных.

Важно: пользовательский интерфейс открывается на frontend-порте Vite `5173`. Backend `3001` нужен только для API и по умолчанию слушает `127.0.0.1`, чтобы не показываться как отдельная preview-страница.

## Настройки подключения и Tor Browser

Если Wikipedia и другие источники недоступны напрямую (блокировка провайдера, корпоративная сеть), откройте раздел **«Настройки»** в приложении и выберите маршрут:

- **Напрямую** — обычное подключение (как в обычном браузере, например Firefox);
- **Tor Browser** — когда Tor Browser запущен, все запросы идут через его SOCKS5-прокси `127.0.0.1:9150` (порт службы `tor` — 9050, свой порт задаётся вручную). Домены резолвит сам Tor, поэтому работают и заблокированные по DNS адреса;
- **Свой прокси** — HTTP/HTTPS/SOCKS5-прокси с ручным адресом и портом.

Кнопка **«Проверить соединение»** опрашивает Wikipedia всеми маршрутами, показывает время отклика, exit-IP и проверку «идёт ли трафик через Tor», и позволяет включить рабочий маршрут одним нажатием. Настройки сохраняются в SQLite (`data/worldhistory.sqlite`) и применяются сразу ко всем запросам поиска, досье и анализу источников.

Переменные окружения для начальной конфигурации (без UI): `PROXY_MODE=tor|custom|direct`, `PROXY_URL=socks5://127.0.0.1:9050`, `TOR_SOCKS_HOST`, `TOR_SOCKS_PORT`, `REQUEST_TIMEOUT_MS`. Сохранённые через интерфейс настройки имеют приоритет.

Как пользоваться Tor Browser:

1. Установите [Tor Browser](https://www.torproject.org/download/) и запустите его (дождитесь соединения с сетью).
2. В разделе «Настройки» выберите режим «Tor Browser» и сохраните.
3. Нажмите «Проверить соединение» — маршрут `Tor Browser (127.0.0.1:9150)` должен стать зелёным.

## SQLite и кэш

При запуске backend автоматически создаёт `data/worldhistory.sqlite`, применяет миграции и включает кэш:

- результаты поиска — 15 минут;
- готовые досье — 24 часа;
- разобранные web-источники — 7 дней.

Просроченный кэш используется как резервный, если внешний провайдер временно недоступен. Путь к базе можно изменить переменной окружения `DB_PATH`. Файлы локальной базы и WAL исключены из Git.

## Live-поиск

Поиск и досье работают через backend и внешние источники, а не через локальный seed-каталог.
Backend агрегирует результаты Wikipedia, Wikidata, OpenAlex и Europeana. Если внешние сервисы недоступны напрямую, поиск честно сообщает причину по каждому провайдеру и предлагает открыть раздел «Настройки», где можно включить Tor Browser или свой прокси. Результаты не подменяются локальными выдуманными данными.
